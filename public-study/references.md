# References

The public edition should reference only public, non-sensitive sources.

## Acceptable reference types

- Government portals
- Public regulatory summaries
- Public company annual reports
- Published framework documents
- Open methodology notes

## Reference rules

- Avoid direct source bundles that reveal a private corpus
- Prefer descriptive citations over file-level pointers
- Do not include credentials, tokens, or private endpoints
- When necessary, cite the class of source rather than a recoverable file path

## Suggested format

- Source category
- Jurisdiction or issuer
- Public document title
- Year or reporting period
